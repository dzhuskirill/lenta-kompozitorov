# Лента композиторов

Наглядная лента для уроков музыкальной литературы: тридцать композиторов,
их годы жизни, страны и эпохи.

**Открыть:** https://dzhuskirill.github.io/lenta-kompozitorov/

Ничего устанавливать не нужно, регистрации нет.

## Что показывает

Полоса каждого композитора стоит на своём месте во времени, цвет — эпоха.
Сразу видно то, что в учебнике приходится держать в голове:

- кто работал в одну эпоху;
- кто жил в одной стране;
- кто из разных стран жил одновременно.

Фильтры по эпохе и стране, карточка с портретом по нажатию, восемь заданий
на закрепление.

## Откуда данные

Годы жизни и страны выгружены из Викиданных — в каждой карточке указан номер
записи, по которому цифру можно проверить. Портреты с Викисклада: двадцать
девять в общественном достоянии, для одного указан автор и лицензия.

Эпоха проставлена по годам творчества, а не по году рождения. Границы эпох
условные, и игра говорит об этом прямо: у Бетховена, Дебюсси, Скрябина,
Рахманинова и Равеля полоса двухцветная.
